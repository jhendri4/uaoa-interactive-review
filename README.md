# UAOA interactive review gallery

Standalone preview of custom interactives for the UAOA eLearning course (outside ScormStack).

**Live preview:** https://jhendri4.github.io/uaoa-interactive-review/

Source course repo: [ND-DAC-DOME/uaoa-elearning](https://github.com/ND-DAC-DOME/uaoa-elearning).

Widgets and the **Buttons** chrome (mini dictionary, support notice/modal, support floater, Continue) are rebuilt from `scripts/` and `docs/` via `python3 scripts/build_review_gallery.py` in the course repo, then synced here for GitHub Pages.
